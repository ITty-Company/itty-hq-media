# SCROLL FILM — мастер-промпт фабрики ITty Company
*(решение Анастасии 18.11.2026: «вот такие должны быть сайты». Референс — каталог scrollprompts.com: Passage, Aurum, Aalto GT, Ashgrove, Cocoa, Emberclay, Qasr, Depth, Eyes Are Mirror… Этот файл — наш собственный промпт, написанный по публичным описаниям и записи экрана; платные промпты сайта не используем и не копируем.)*

Этот файл важнее всех остальных правил стиля. Если `DESIGN_STANDARD.md` в чём-то с ним расходится — прав этот файл.

## 0. Суть в одной фразе
**Сайт = короткометражный фильм, который зритель «проматывает» скроллом.** Весь первый экран и дальше — один непрерывный кадр-полёт камеры (дрон, макро, наезд), который скролл перематывает вперёд и назад покадрово. Поверх фильма — тихие строки-главы, тонкий HUD и минимум интерфейса. Никаких «блоков с карточками»: каждая секция — следующая сцена того же фильма или переход-растворение в новую сцену.

Как это выглядит в референсах:
- **Passage** — дрон вылетает из тёмного проёма храма → колоннады, пальмы → низко над рекой с парусами → вверх к вершине пирамиды на закате. Потом 3D-галерея крутит три скульптуры, камера влетает в последнюю, и через радиальное растворение начинается второй фильм — проход по каменному коридору в освещённый зал.
- **Aurum** (аренда авто) — одна ночная поездка: камера ныряет с небоскрёба вниз до сиденья водителя; HUD считает высоту вниз, потом скорость вверх; шоурум растворяется шумом в набранную по буквам фразу.
- **Cocoa** — «всё начинается со стручка»: стручок в тёплой темноте → раскрывается → бобы парят в slow-motion → ферментация → взрыв какао-пыли → темперирование. Каждая глава — одно слово антиквой («THE POD», «THE FERMENT», «THE TEMPER»).
- **Qasr / Misty Glass** — макро-жидкости: шоколад и оливковое масло льются и складываются в форму.
- **Eyes Are Mirror / Depth** — камера влетает в радужку глаза / уходит под лёд.

## 1. Как переводить клиента в фильм (story-architect)
1. **Один маршрут камеры** через мир клиента, от «снаружи» к «самому сердцу продукта» и обратно к людям/контакту. Формула: *порог → путь → объект крупно → внутрь объекта → результат → свет/финал.*
   - nagelstudio: свеча на подоконнике снаружи салона → камера влетает в окно → мимо стола мастера → капля геля падает в slow-motion → растекается по ногтю → рука поворачивается к свету.
   - snackbar: ночная улица, неон → дверь → фритюр, золотой всплеск → картошка взлетает в slow-motion → падает в кулёк → тарелка на стойке.
   - автосервис: ночная трасса → фары → въезд в бокс → подъёмник поднимает машину → камера проходит под днищем → искры → машина выезжает на рассвет.
   - пекарня: поле на рассвете → мука облаком → тесто тянется → печь, жар → корка трескается.
   - строитель/schilder: чертёж на столе → линии поднимаются в 3D-каркас → стены, свет в окнах → готовый дом в сумерках.
2. **Фильмы и ключевые кадры.** Маршрут режется на **3–4 фильма по 5 с**, их склеивают «кадр в кадр»: *последний кадр фильма N = первый кадр фильма N+1.* Для этого нужно **4–6 ключевых кадров (keyframes)** — по одному на каждый стык. Итого на сайт: 4–6 keyframes + 3–4 фильма + 6–9 стоп-кадров для журнала.
3. **Главы ставятся по битам фильма**, а не по экранам: «на 0–18% главного фильма — строка 1, 22–40% — строка 2…». Каждая глава — одна короткая фраза (2–6 слов, с точкой) + одна строка подписи. Длинный текст — ниже, в «журнале».
4. **Второй акт** (необязательно, но желательно): после главного фильма — сцена-переход (порталом/шумом/дымом) во второй мир: интерьер, продукт в 3D-галерее или второй короткий фильм.
5. Мобильная версия — тот же фильм (кадр 9:16 кропом по центру объекта или отдельные вертикальные кадры), главы снизу.

### Обязательный выход story-architect: `STORY.md` = SHOT LIST
Для каждого keyframe: что в кадре, ракурс, свет, где «пустое место» под текст, промпт (EN).
Для каждого фильма: from-кадр → to-кадр, движение камеры одним предложением («slow continuous drone push forward through the doorway, no cuts»), длительность 5 с, что меняется, на какие % скролла ложится, какие главы поверх.

## 2. Как это строится (builder)

### 2.1 Медиа-конвейер
**Режим A — настоящий фильм (лучший, как в референсах).** Нужно разрешение Анастасии на видео (сейчас в задаче цикла видео в Higgsfield запрещено). Цена на 18.11.2026: MiniMax H3 Max 5 с 768p ≈ 12,5 кредита; Seedance 2.5 5 с 720p ≈ 35 (черновик 480p ≈ 15). Сайт с 3 фильмами ≈ 40–110 кредитов.
1. Keyframes: `gpt_image_2_6`, 16:9, один общий «якорь» (камера, свет, палитра, зерно) — как сейчас.
2. Фильмы: модель с `start_image` + `end_image` (MiniMax H3 Max / Seedance 2.5 omni_reference / FLUX 3 Video). Промпт фильма = якорь + одно непрерывное движение камеры + «no cuts, no text, no people looking at camera, smooth constant speed, cinematic, photoreal». Звук выключить.
3. Склейка: если стык «прыгает» — взять последний кадр готового фильма (`ffmpeg -sseof -0.05 -i f1.mp4 -frames:v 1 last.png`), загрузить и дать как `start_image` следующему.
4. Кадры для скраба:
   ```bash
   # desktop: 1280px, 24 fps → ~120 кадров на 5 с
   ffmpeg -i film1.mp4 -vf "fps=24,scale=1280:-2" -c:v libwebp -quality 70 frames/d/f1_%04d.webp
   # mobile: 720px по высоте 9:16 кроп по центру объекта
   ffmpeg -i film1.mp4 -vf "fps=20,crop=ih*9/16:ih:(iw-ih*9/16)*0.6:0,scale=720:-2" -c:v libwebp -quality 65 frames/m/f1_%04d.webp
   ```
   Цель: ≤ 60 КБ на кадр desktop, весь фильм ≤ 8 МБ; первые 15 кадров грузятся сразу, остальные — фоном по порядку, затем «прореженные» пропуски.

**Режим B — псевдо-фильм без видео (по умолчанию, пока видео не разрешено).** Фильм делается кодом из keyframes:
1. На каждый keyframe — карта глубины (локально в облаке: `transformers` + `depth-anything-small`, CPU) и, где нужно, вырезанный передний план.
2. WebGL-шейдер «2.5D-камера»: по прогрессу скролла камера летит вперёд (dolly-in по глубине с параллаксом слоёв), чуть поворачивает, добавляет дымку и частицы; на стыке — переход в следующий keyframe тем же движением (zoom-through: камера влетает в светлую точку/проём, и из неё раскрывается следующий кадр). Так стыков не видно.
3. Плюс макро-эффекты кодом: капля/жидкость (метаболлы), пыль/искры (частицы), свет (bloom), блик по стеклу.
Режим B обязан выглядеть как фильм, а не как слайдшоу: движение камеры постоянное, ни одного статичного кадра, ни одного «fade к чёрному и новая картинка».

### 2.2 Скелет страницы
```
<loader>        — логотип + тонкая линия процента (пока грузятся первые кадры)
<nav>           — лого слева, 3–4 пункта, пилюля CTA справа; прозрачный, тонкий
<section film>  — высота = 500–700vh; внутри sticky <canvas> 100vh
                  поверх: главы (absolute, появляются/уходят по % фильма),
                  HUD: таймкод «00:07 / 00:20» или счётчик по теме (высота, °C, км/ч, мин),
                  боковая рельса глав (точки + названия), подпись сцены внизу слева,
                  «scroll»-подсказка в начале
<section portal>— WebGL-растворение (радиальный портал / шум / дым / капля) во 2-ю сцену
<section act2>  — 3D-галерея (three.js, GLB) ИЛИ второй скраб-фильм ИЛИ пиннинг-галерея
<section journal> — «журнал»: 3–6 стоп-кадров из фильма + настоящий текст, услуги/цены,
                  панорама (горизонтальный скролл одного широкого кадра)
<section final> — кадр-финал фильма, большой тезис, CTA, контакты
<footer>        — главы-ссылки (прыжок к % фильма), адрес, часы, «Ontwerpvoorstel — ITty Company»
overlay         — плёночное зерно (canvas/svg noise, 4–6% opacity), лёгкая виньетка
```
Внутренние страницы (минимум Behandelingen/Diensten, Over ons, Contact): у каждой свой короткий скраб-фильм или псевдо-фильм на 200–300vh в hero, дальше журнал. Переход между страницами — та же «шторка-портал».

### 2.3 Скраб-плеер (ядро)
- Один `<canvas>`, `drawImage` текущего кадра с `object-fit: cover`-логикой и DPR ≤ 2.
- Прогресс = позиция скролла внутри секции, **сглаживание lerp 0.08–0.12** (инерция как у Lenis), кадр = `round(p * (N-1))`; если кадр ещё не загружен — показать ближайший загруженный.
- Несколько фильмов подряд = один массив кадров (склейка в коде), главы по глобальному %.
- Колесо/тач работают в обе стороны; на мобильных — тот же плеер, вертикальные кадры.
- `prefers-reduced-motion`: показывать 4–6 стоп-кадров с текстом без скраба.
- Без JS: стоп-кадры `<img>` + весь текст видимы.

### 2.4 Переходы-растворения (WebGL, один фрагментный шейдер с режимами)
`radial` (портал из точки света), `noise` (пиксельный шум/туман), `smoke` (fbm-дым), `drip` (капля/жидкость), `ink` (растекание по маске). Uniform `progress` от скролла, 0→1 за ~100vh. Резкий crossfade запрещён.

### 2.5 3D-галерея (если есть второй акт)
three.js + GLTFLoader локально в `assets/vendor/`. Три объекта ниши (свеча, флакон, кисть / деталь двигателя / круассан). Модель нормализуется: bounding box → масштаб к высоте 1, центр в 0, стоит вертикально. Фазы по скроллу: поворот на 360° → наезд камеры на поверхность → подпись + стрелки ← →. Источник GLB: Higgsfield `generate_3d` из keyframe-картинки предмета или свободные сканы (CC0, указать источник). Нет модели — не делать галерею, заменить пиннинг-галереей стоп-кадров.

### 2.6 Типографика и цвет
- Тёмная база + один светлый + один акцент (как в «★ ГЛАВНЫЙ СТИЛЬ»), но цвет в основном **живёт в самом фильме** — интерфейс почти монохромный.
- Шрифтовая пара «журнал»: крупная антиква или широкий гротеск для глав (Cormorant Garamond, Fraunces, Bodoni Moda, Italiana, Syne, Unbounded, Archivo Expanded, Big Shoulders) + мелкий моно/гротеск для HUD и подписей (JetBrains Mono, IBM Plex Mono, DM Mono, Space Grotesk) в капсе с трекингом 0.12–0.2em. Не повторять пары из `journal/fonts.md`.
- Главы: 1 строка, 48–120px desktop, отступ от края 6vw, никогда не по центру поверх объекта.
- HUD: 11–12px моно, цифры tabular-nums.

### 2.7 Тексты (copywriter)
- Поверх фильма — только короткие строки-главы (2–6 слов) и подписи (≤ 12 слов). Пример: «eerst de vlam.» / «dan de druppel.» / «en dan: jouw handen.»
- Весь настоящий текст (услуги, цены, о нас, отзывы-рейтинг) — в «журнале» и на внутренних страницах, ≥ 900 слов на сайт. Правила честности — прежние.

## 3. Шаблоны промптов
**Якорь (вставлять в каждый keyframe и фильм):**
`Cinematic film still, [палитра: deep <base> darkness, <accent> light source, <light> rim], anamorphic 35mm look, slow atmospheric haze, fine film grain, photoreal, no text, no logos, no watermark, no people facing camera.`

**Keyframe:** `ANCHOR + [сцена], camera at [высота/ракурс], subject [где], empty dark area [слева/сверху] for a headline, 16:9.`

**Фильм (start→end):** `ANCHOR. One continuous shot, no cuts: the camera [движение: glides forward / descends / orbits / pushes into] from the first frame to the last frame, [что происходит], constant smooth speed, gentle parallax, 5 seconds, silent.`

**Мобильный keyframe:** тот же, `9:16, subject centred, headline space at the bottom`.

## 4. Критерии приёмки (critic) — «уровень scrollprompts»
1. **Фильм**: первый экран — уже кадр фильма; скролл реально «ведёт камеру», движение непрерывно в обе стороны, стыки фильмов не видны. (Слайдшоу/fade между картинками = максимум 5.)
2. **Режиссура**: у маршрута есть начало, путь, кульминация и финал; главы стоят на битах (фраза появляется в момент, когда в кадре то, о чём она).
3. **Тишина интерфейса**: минимум элементов поверх фильма; HUD/главы тонкие и аккуратные; зерно и виньетка есть.
4. **Переход-портал** во второй акт или на внутреннюю страницу — шейдер, не crossfade.
5. **Журнал**: стоп-кадры + настоящий текст, услуги и контакты легко найти.
6. **Производительность**: первый кадр < 2 с, плавно 60 fps на desktop, ≥ 30 на телефоне, вес главной ≤ 15 МБ (кадры подгружаются фоном), ноль ошибок консоли.
7. **Мобильная**: вертикальный фильм, главы читаются, CTA в зоне большого пальца.
8. **Честность**: AI-кадры с людьми — «Voorbeeldbeeld», места — «Sfeerbeeld»; без чужих логотипов/брендов.
Итог = минимум; ≥ 9 → APPROVE.

## 5. Порядок работы в цикле
lead-scout → palette → type (пара «журнал») → **story-architect: маршрут камеры + SHOT LIST** → copywriter (главы по битам + журнал) → keyframes → [Режим A: фильмы → кадры | Режим B: глубины + шейдер-камера] → builder (скраб-плеер, главы, HUD, портал, журнал, внутренние страницы) ⇄ critic (≤ 4 раунда, до 9/10) → видео-демо прокрутки 40 с.
